# Trabajo_Final_Data_Office

# Justificación del Conjunto de Datos Seleccionado

## 📊 Información General
* **Fuente:** Kaggle – *AI Adoption in Fortune 500 Companies (2020–2025)*
* **Enlace:** [Acceder al Dataset](https://www.kaggle.com/datasets/abidhussai512/ai-adoption-in-fortune-500-companies-20202025)

---

## 🔍 Contexto del Dataset
El dataset seleccionado registra el comportamiento de adopción de inteligencia artificial en **1.000 empresas de tipo Fortune 500** durante el período **2020–2025**. Cuenta con un total de **6.000 registros** y un conjunto robusto de variables que incluyen:
* **Identificación:** Sector industrial, país y tamaño organizacional.
* **Operación:** Casos de uso específicos de IA.
* **Rendimiento:** Retorno sobre la inversión (AI ROI %) y nivel de madurez (AI Maturity Score 0–100).

---

## 🎯 Pertinencia con el Problema y la Estrategia
Este dataset permite abordar una necesidad real del entorno empresarial actual: **comprender qué factores determinan una adopción exitosa de IA y cuál es su impacto financiero medible.** La cobertura temporal de seis años es un factor crítico, ya que posibilita:
1.  Identificar tendencias evolutivas post-pandemia.
2.  Enriquecer el análisis estratégico con datos longitudinales.
3.  Formular recomendaciones basadas en evidencia sólida sobre la madurez tecnológica.

---

## 🛠️ Pertinencia Técnica
La estructura del dataset es ideal para el desarrollo de un **pipeline de datos completo**:

* **Tipología de Datos:** Contiene variables categóricas (industria, país, tipo de empresa) y numéricas (ROI, madurez, ingresos, empleados), facilitando las fases de limpieza y normalización.
* **Capacidad de Análisis:** Su volumen de 6.000 registros es suficiente para aplicar técnicas de análisis estadístico robustas y, potencialmente, modelos predictivos.
* **Análisis Exploratorio (EDA):** La naturaleza de los datos permite construir visualizaciones complejas para la toma de decisiones estratégicas.

---

## 🚀 Alineación con los Entregables
Al tratarse de datos abiertos disponibles en Kaggle, el dataset garantiza:
* **Accesibilidad y Reproducebilidad:** Facilita la auditoría de los datos y el trabajo colaborativo.
* **Integración:** Puede integrarse directamente en un repositorio de GitHub con notebooks en Python.
* **Coherencia:** Asegura que todos los entregables (limpieza, EDA, gobierno de datos y dashboard) se desarrollen de manera armónica sobre una misma fuente de verdad.
